このリポジトリはハッカソンで作成した「調整ちゃん」のリポジトリです。

## Getting Started

前提として、[公式の導入手順](https://mise.jdx.dev/getting-started.html) に従って mise をインストールし、シェルで有効にしてください。

`make setup` で Node 24・Herdr と依存パッケージが入ります。

```bash
make setup
make dev
```

`make` でターゲット一覧を表示できます。

## Storybook Usage

以下のコマンドでポート6006番にStorybookが起動します

```bash
make storybook
```
