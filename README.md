このリポジトリはハッカソンで作成した「調整ちゃん」のリポジトリです。

## Getting Started

```bash
make setup
make dev
```

`make` でターゲット一覧を表示できます。

## Storybook Usage

以下のコマンドでポート6006番にStorybookが起動します

```bash
make storybook
```
